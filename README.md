# 🎁 Sorteio de Amigo Secreto

Aplicação web desenvolvida durante os cursos de lógica de programação da Alura. O projeto tem como objetivo proporcionar uma interface simples e intuitiva para organizar brincadeiras de amigo secreto, permitindo o cadastro de nomes e a realização do sorteio automático entre os participantes.

---

## 🚀 Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**

---

## 🛠️ Funcionalidades

* **Adição de Participantes**: Insira nomes de amigos em uma lista interativa através de um campo de texto.
* **Validação de Entrada**: O sistema verifica se o campo está vazio ou se há nomes duplicados antes de incluí-los na lista.
* **Sorteio Aleatório**: Realiza o embaralhamento e a distribuição dos nomes para definir quem tira quem de forma justa.
* **Interface Responsiva**: Estilização moderna com suporte a recursos visuais e adaptada para diferentes tamanhos de tela.
